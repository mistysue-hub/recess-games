# This Course Is a Paradigm

Summary: Kuhn's tools turned on this course: how it came to be, the mistakes fact-checking caught, and the anomalies each module planted. Critique of the course is the lesson.

**Start here:** use the level chosen in M01 → say the hook word for word → open the reading at that level → AGENTS.md session flow.

Estimated time: 25 minutes (reading about 6, talk about 9, activity about 10).

## Learning targets

- explain how this course works like a paradigm or textbook
- identify at least one simplification or omission in the course

## Tutor guidance

**Hook (word for word):**

> Quick vote before you read. True or false: this course told you history exactly as it happened. How sure are you, 0 to 100?

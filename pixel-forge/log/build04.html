Build 04

Tower Hop, part 1

Ships today

gravity, a jump, a tower of platforms that builds itself forever, a camera that follows you up, and stars that drift at two speeds.

Meteor Drift was a game about dodging. Tower Hop is a game about falling, and about the one moment per second when you don't. A hero, a stack of platforms, a jump key. Miss a platform and you drop out of the bottom of the screen. The twist is that the tower never ends, because we build it while you climb. Make a new folder, build04-tower-hop, and start a fresh main.lua (or unzip the starter kit). Bring over the title, playing and game-over skeleton from Build 03; the kit already has it.

Step 1The hero, and gravity

function love.load()
  love.window.setTitle("Tower Hop")
  gravity = 1400
  state = "title"
  resetGame()
end

function resetGame()
  player = { x = 384, y = 500, w = 32, h = 32, vy = 0, speed = 280, jump = -640, onGround = false }
  platforms = { { x = 300, y = 560, w = 200, h = 16 } }
  cameraY = 0
  score = 0
end

New field: vy, the hero's vertical speed in pixels per second. Gravity is not a position; it's a change to speed. Every frame, speed goes up by gravity dt, then position goes up by vy dt. Two lines, and your hero falls like a real thing:

function love.update(dt)
  if state ~= "playing" then return end
  if love.keyboard.isDown("left") then player.x = player.x - player.speed * dt end
  if love.keyboard.isDown("right") then player.x = player.x + player.speed * dt end
  if player.x > 800 then player.x = -player.w end
  if player.x + player.w < 0 then player.x = 800 end

  local feetBefore = player.y + player.h
  player.vy = player.vy + gravity * dt
  player.y = player.y + player.vy * dt
  local feetAfter = player.y + player.h
end

return at the top is a trick: if we're not playing, leave the function right away. The two x checks make the hero wrap around the edges, which is how every good hopper works. Draw the hero as a yellow square and the platform as a green bar, run it, and watch the hero fall straight through the platform and off the bottom of the world. Good. That's correct. We haven't told it what a floor is.

Step 2Landing and jumping

A landing is: you were above the platform's top before this frame, you're at or below it after, you're over it sideways, and you're moving down. That's why we saved feetBefore and feetAfter.

  player.onGround = false
  if player.vy >= 0 then
    for i, p in ipairs(platforms) do
      if feetBefore <= p.y and feetAfter >= p.y
         and player.x + player.w > p.x and player.x < p.x + p.w then
        player.y = p.y - player.h
        player.vy = 0
        player.onGround = true
      end
    end
  end

Only the top counts. Jump up through a platform from underneath and you pass right through, which feels great and costs nothing. Jumping is a key press, and only from the ground:

function love.keypressed(key)
  if key == "space" and state == "playing" and player.onGround then
    player.vy = player.jump
    player.onGround = false
  end
end

jump is negative because up is negative. Run it. Land, jump, land. If that first jump doesn't make you grin a little, check your pulse.

Step 3A tower that builds itself

We never place platforms by hand. A function makes the next one a random distance above the last, and a random distance sideways from it, so it's always reachable:

function spawnPlatform()
  nextY = nextY - math.random(70, 110)
  lastX = math.max(0, math.min(680, lastX + math.random(-220, 220)))
  table.insert(platforms, { x = lastX, y = nextY, w = 120, h = 16 })
end

Add nextY = 560 and lastX = 300 to resetGame, then, at the end of resetGame, call it until there's a tower above the screen:

  while nextY > -400 do spawnPlatform() end

while repeats until its question is false. Run it and climb. You'll reach the top of the window and keep going, into the part the window doesn't show.

Step 4The camera

A camera in a 2D game is a lie we tell love.draw: shift everything down by cameraY before drawing, and the world appears to scroll. cameraY is the world coordinate at the top of the window.

function love.draw()
  love.graphics.push()
  love.graphics.translate(0, -cameraY)
  love.graphics.setColor(0.45, 0.8, 0.55)
  for i, p in ipairs(platforms) do
    love.graphics.rectangle("fill", p.x, p.y, p.w, p.h)
  end
  love.graphics.setColor(1, 0.85, 0.3)
  love.graphics.rectangle("fill", player.x, player.y, player.w, player.h)
  love.graphics.pop()
  love.graphics.setColor(1, 1, 1)
  love.graphics.print("height: " .. score, 10, 10)
end

push remembers where the drawing pen is, translate moves it, pop puts it back. The score is printed after pop, so it stays glued to the window. The camera only ever moves up, and only when the hero gets near the top:

  if player.y < cameraY + 250 then cameraY = player.y - 250 end
  score = math.max(score, math.floor(-cameraY / 10))

Run it. Climb. The tower scrolls, the number climbs with you.

Step 5Endless

Three jobs at the end of love.update: keep spawning above the camera, delete platforms far below it, and notice when the hero falls out:

  while nextY > cameraY - 100 do spawnPlatform() end
  for i = #platforms, 1, -1 do
    if platforms[i].y > cameraY + 700 then table.remove(platforms, i) end
  end
  if player.y > cameraY + 650 then state = "gameover" end

Same backward loop as Build 02. Hook the gameover state up to your title screen and retry, and you have a complete endless game. Jamie's record is 41. Jamie claims the platforms "moved on purpose." They don't. Yet.

Step 6Parallax stars

Parallax is the oldest trick in 2D: things far away scroll slower. Make eighty stars once, in love.load:

  stars = {}
  for i = 1, 80 do
    table.insert(stars, { x = math.random(0, 800), y = math.random(0, 600), size = math.random(1, 3) })
  end

Draw them first, before push, so they're not part of the world:

  for i, s in ipairs(stars) do
    local rate = 0.3
    if s.size == 3 then rate = 0.6 end
    local sy = (s.y - cameraY * rate) % 600
    love.graphics.setColor(1, 1, 1, 0.3 + s.size * 0.2)
    love.graphics.rectangle("fill", s.x, sy, s.size, s.size)
  end

% is remainder: it wraps sy back into 0 to 600 forever, so the sky never runs out. Big stars move at 0.6 of the camera, small ones at 0.3, and your eye reads depth. Run it and climb. It looks like a real sky now.

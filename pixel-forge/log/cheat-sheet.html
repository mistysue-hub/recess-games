LÖVE: the loop

function love.load() end         -- once, at start
function love.update(dt) end     -- every frame; dt = seconds since last frame
function love.draw() end         -- every frame, after update
function love.keypressed(key) end  -- once per key press
function love.mousepressed(x, y, button) end  -- once per click

Always multiply a speed by dt: x = x + speed * dt.

Reading an error

LÖVE shows a blue screen. The first line names the file and line number, like main.lua:27:. Go to that line.

Error saysUsually means
attempt to index a nil valueYou used thing.x but thing doesn't exist yet (typo, or made in the wrong place)
attempt to compare number with nilA field is missing, like a rock with no speed
attempt to perform arithmetic on a nil valueSame idea: a number you're adding doesn't exist
'end' expectedA block (if, for, function) isn't closed
'then' expectedAn if line is missing then, or has = instead of ==
attempt to call a nil valueYou called a function that doesn't exist (check the spelling and capitals)

AABB overlap (copy once, use forever)

function overlaps(a, b)
  return a.x < b.x + b.w and b.x < a.x + a.w
     and a.y < b.y + b.h and b.y < a.y + a.h
end

Step 1A hook that swings

Right now the crate appears under the crane and drops straight down. Real cranes have a hook on a cable, and a hook on a cable swings. Box2D does this with a joint: a rule that ties two bodies together.

function love.load()
  -- after the world and ground:
  anchor = {}
  anchor.body = love.physics.newBody(world, 400, 30, "kinematic")
  hook = {}
  hook.body = love.physics.newBody(world, 400, 110, "dynamic")
  hook.shape = love.physics.newCircleShape(8)
  hook.fixture = love.physics.newFixture(hook.body, hook.shape, 2)
  hook.fixture:setMask(1)
  cable = love.physics.newDistanceJoint(anchor.body, hook.body, 400, 30, 400, 110)
end

The anchor is kinematic: it moves because you tell it to, not because gravity does. The hook is a small heavy dynamic body hanging from the anchor on a distance joint, which is Box2D for "stay exactly 80 pixels apart." setMask(1) stops the hook from colliding with crates (all fixtures are in category 1 unless you say otherwise). Now the crane moves the anchor instead of a plain number:

  anchor.body:setLinearVelocity(crane.dir * crane.speed, 0)
  if anchor.body:getX() > 740 or anchor.body:getX() < 60 then
    crane.dir = -crane.dir
  end

And a dropped crate appears at the hook's position, moving at the hook's speed:

  c.body:setPosition(hook.body:getX(), hook.body:getY() + 30)
  c.body:setLinearVelocity(hook.body:getLinearVelocity())

Run it. The hook lags behind the crane and swings when it turns. Drop a crate mid-swing and it flies sideways. The game just got twice as hard and twice as good, and you changed about ten lines.

Step 2A menu with a settings screen

Add two states, "menu" and "settings". The menu shows the title, "space to play" and "s for settings". Settings shows one thing: a volume slider you build out of rectangles.

  volume = 0.7
  slider = { x = 250, y = 300, w = 300, h = 10, dragging = false }
function drawSlider()
  love.graphics.setColor(0.3, 0.3, 0.35)
  love.graphics.rectangle("fill", slider.x, slider.y, slider.w, slider.h)
  love.graphics.setColor(0.9, 0.6, 0.3)
  love.graphics.rectangle("fill", slider.x, slider.y, slider.w * volume, slider.h)
  love.graphics.circle("fill", slider.x + slider.w * volume, slider.y + slider.h / 2, 12)
end

The knob sits at x + w * volume, so volume 0 is the left end and 1 is the right. Dragging is three functions:

function love.mousepressed(x, y, button)
  if state == "settings" and y > slider.y - 15 and y < slider.y + 25
     and x > slider.x - 15 and x < slider.x + slider.w + 15 then
    slider.dragging = true
  end
end

function love.mousereleased(x, y, button)
  slider.dragging = false
end

function love.mousemoved(x, y)
  if slider.dragging then
    volume = math.max(0, math.min(1, (x - slider.x) / slider.w))
    love.audio.setVolume(volume)
  end
end

(x - slider.x) / slider.w turns a mouse position into a number from 0 to 1; math.max and math.min keep it there when the mouse overshoots. love.audio.setVolume is the master volume for every sound in the game. Press escape in settings to go back to the menu.

Step 3Music that loops

Find a music track you're allowed to use. Kenney's music packs are CC0 (the link is in this module); or make a loop in any free tool. Save it as assets/music.ogg. Then:

  local ok, m = pcall(love.audio.newSource, "assets/music.ogg", "stream")
  if ok then
    music = m
    music:setLooping(true)
    music:play()
  end

"stream" plays the file bit by bit instead of loading all of it, which is right for music and wrong for short sounds. setLooping(true) means it never ends. The pcall means the game still runs if the file is missing, which matters when you hand the game to someone else and forget the folder. Now the slider does something you can hear.

Step 4Game feel

Right now a crate landing on the tower looks like a crate landing on the tower. It should feel like it. Two tricks, and you'll pick which ones to ship:

Screen shake. Keep a shake number. When a heavy landing happens (in beginContact), set shake = 6. In draw, before anything else: love.graphics.translate(math.random(-shake, shake), math.random(-shake, shake)), and in update: shake = math.max(0, shake - 30 * dt).

Squash. When a crate lands, set c.squash = 0.2. Draw its rectangle with width w (1 + c.squash) and height h (1 - c.squash), and shrink c.squash toward 0 every frame. Crates look like they thump.

Box2D hands beginContact two fixtures. To find which crate landed, loop over crates and compare c.fixture == a or c.fixture == b.

Step 5Ship it as one file

A LÖVE game is a folder. A .love file is that folder zipped, with a different name. On Windows: open your build folder, select everything inside it (not the folder itself), right-click, Send to, Compressed folder, then rename the result stack-attack.love. On Mac: same, with Compress, then rename. Double-click it on any computer with LÖVE installed and your game runs. That's distribution. Studios with a hundred people do the same thing with more steps.

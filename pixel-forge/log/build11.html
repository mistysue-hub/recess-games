Step 1A hook that swings

Right now the crate appears under the crane and drops straight down. Real cranes have a hook on a cable, and a hook on a cable swings. Box2D does this with a joint: a rule that ties two bodies together. Add these lines to the end of your existing love.load, after the ground (not a second love.load):

  anchor = {}
  anchor.body = love.physics.newBody(world, 400, 30, "kinematic")
  hook = {}
  hook.body = love.physics.newBody(world, 400, 110, "dynamic")
  hook.shape = love.physics.newCircleShape(8)
  hook.fixture = love.physics.newFixture(hook.body, hook.shape, 2)
  hook.fixture:setMask(1)
  cable = love.physics.newDistanceJoint(anchor.body, hook.body, 400, 30, 400, 110)

The anchor is kinematic: it moves because you tell it to, not because gravity does. The hook is a small heavy dynamic body hanging from the anchor on a distance joint, which is Box2D for "stay exactly 80 pixels apart." setMask(1) stops the hook from colliding with crates (all fixtures are in category 1 unless you say otherwise). Now the crane moves the anchor instead of a plain number:

  local x = anchor.body:getX()
  if x > 740 then crane.dir = -1 elseif x < 60 then crane.dir = 1 end
  anchor.body:setLinearVelocity(crane.dir * crane.speed, 0)

Decide the direction first, then set the speed. Flip it the other way round and the anchor gets one extra frame past the edge every time, bounces in place and jams there; the first version of this Build Log did exactly that. Replace Build 10's crane lines with these; crane.x is no longer used. The hook needs drawing too, or you'll never see it swing. In love.draw, in place of the old hook rectangle:

  love.graphics.setColor(0.6, 0.6, 0.65)
  love.graphics.line(anchor.body:getX(), anchor.body:getY(), hook.body:getX(), hook.body:getY())
  love.graphics.circle("fill", hook.body:getX(), hook.body:getY(), 8)

A line for the cable, a circle for the hook. And a dropped crate appears at the hook's position, moving at the hook's speed:

  c.body:setPosition(hook.body:getX(), hook.body:getY() + 30)
  c.body:setLinearVelocity(hook.body:getLinearVelocity())

Run it. The hook lags behind the crane and swings when it turns. Drop a crate mid-swing and it flies sideways. The game just got twice as hard and twice as good, and you changed about ten lines.

Step 2A menu with a settings screen

Add two states, "menu" and "settings". In love.load, change state = "playing" to state = "menu"; resetGame() from Build 10 is what moves it to "playing". The menu shows the title, "space to play" and "s for settings". Settings shows one thing: a volume slider you build out of rectangles. In love.load:

  volume = 0.7
  love.audio.setVolume(volume)
  slider = { x = 250, y = 300, w = 300, h = 10, dragging = false }

The setVolume line makes 0.7 real from the first frame; without it the game plays at full volume until the first drag.

function drawSlider()
  love.graphics.setColor(0.3, 0.3, 0.35)
  love.graphics.rectangle("fill", slider.x, slider.y, slider.w, slider.h)
  love.graphics.setColor(0.9, 0.6, 0.3)
  love.graphics.rectangle("fill", slider.x, slider.y, slider.w * volume, slider.h)
  love.graphics.circle("fill", slider.x + slider.w * volume, slider.y + slider.h / 2, 12)
end

The knob sits at x + w * volume, so volume 0 is the left end and 1 is the right. Dragging is three functions:

function love.mousepressed(x, y, button)
  if state == "settings" and y > slider.y - 15 and y < slider.y + 25
     and x > slider.x - 15 and x < slider.x + slider.w + 15 then
    slider.dragging = true
  end
end

function love.mousereleased(x, y, button)
  slider.dragging = false
end

function love.mousemoved(x, y)
  if slider.dragging then
    volume = math.max(0, math.min(1, (x - slider.x) / slider.w))
    love.audio.setVolume(volume)
  end
end

(x - slider.x) / slider.w turns a mouse position into a number from 0 to 1; math.max and math.min keep it there when the mouse overshoots. love.audio.setVolume is the master volume for every sound in the game. One more thing: Build 10's escape key quits from anywhere, which is rude on a settings screen. Replace love.keypressed with one that asks what state it's in first:

function love.keypressed(key)
  if state == "menu" then
    if key == "space" then resetGame() end
    if key == "s" then state = "settings" end
    if key == "escape" then love.event.quit() end
  elseif state == "settings" then
    if key == "escape" then state = "menu" end
  elseif state == "playing" then
    if key == "space" then dropCrate() end
    if key == "escape" then state = "menu" end
  elseif state == "gameover" then
    if key == "space" then resetGame() end
    if key == "escape" then state = "menu" end
  end
end

Same key, four meanings, one if per state. That's the whole reason state machines exist.

Step 3Music that loops

Find a music track you're allowed to use. Kenney's pack at kenney.nl/assets/music-jingles is CC0, though most of its tracks are short jingles; any CC0 loop works, or make a ten-second loop in any free tool and let setLooping repeat it. Save it in your assets folder with the name the code below uses. Then:

  local ok, m = pcall(love.audio.newSource, "assets/music.ogg", "stream")
  if ok then
    music = m
    music:setLooping(true)
    music:play()
  end

"stream" plays the file bit by bit instead of loading all of it, which is right for music and wrong for short sounds. setLooping(true) means it never ends. The pcall means the game still runs if the file is missing, which matters when you hand the game to someone else and forget the folder. Now the slider does something you can hear.

Step 4Game feel

You did shake and squash in Build 10, Step 7. Both still work with the hook, because they never touched the physics. Ship-It 1 asks for two more feel effects on top of those; the list is there. The pattern is always the same: beginContact knows when a landing happens and which crate it was (c.fixture == a or c.fixture == b), so that's where every effect starts, and love.update is where it fades.

Step 5Ship it as one file

A LÖVE game is a folder. A .love file is that folder zipped, with a different name. On Windows, first make file endings visible (View, Show, File name extensions), or your rename will silently produce a file ending in .love.zip. Then open your build folder, select everything inside it (not the folder itself), right-click, then Compress to ZIP file (Windows 11) or Send to, Compressed folder (older Windows), and rename the result stack-attack.love. On Mac: same, with Compress, then rename. One trap: inside a .love, capital letters in file names must match your code exactly; from a folder, Windows and Mac forgive Thud for thud, but the packed file doesn't. Double-click it on any computer with LÖVE installed and your game runs. That's distribution. Studios with a hundred people do the same thing with more steps.

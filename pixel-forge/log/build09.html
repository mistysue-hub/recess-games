Lantern Keep, part 2

Ships today

wisps with moods, a dialog box that types itself out, a bag, an iron key, and a door that cares whether you have it. Lantern Keep becomes a finished game.

Copy build08-lantern-keep to build09-lantern-keep. Keep the old build; we always do. Today is about things that decide: an enemy that decides to chase, a door that decides to open. Every one is an if on a piece of state, which you've been writing since Blip. There are just more of them now.

Step 1Wisps and their three moods

A wisp is a little light that drifts around the keep. It has three moods, and you know what that is: a state machine, like title/playing/gameover in Build 03, but inside one object. Add a class below Entity:

Wisp = Class()

function Wisp:init(x, y)
  self.x, self.y, self.w, self.h = x, y, 20, 20
  self.homeX, self.homeY = x, y
  self.speed = 70
  self.state = "wander"
  self.timer = 0
  self.dirX, self.dirY = 1, 0
end
Wisp.move = Entity.move
Wisp.center = Entity.center

The last two lines borrow move and center from Entity so wisps slide along walls too. center and distance are the two helpers you wrote at the end of Build 08, Step 4; if your Build 08 doesn't have them, copy them from that Build Log now. Now the moods:

function Wisp:update(dt)
  local d = distance(self, player)

  if self.state == "wander" then
    self.timer = self.timer - dt
    if self.timer <= 0 then
      local angle = math.random() * 2 * math.pi
      self.dirX, self.dirY = math.cos(angle), math.sin(angle)
      self.timer = math.random(1, 3)
    end
    self:move(self.dirX * self.speed * dt, self.dirY * self.speed * dt)
    if d < 120 then self.state = "chase" end

  elseif self.state == "chase" then
    local px, py = player:center()
    local wx, wy = self:center()
    local len = math.max(1, math.sqrt((px - wx) ^ 2 + (py - wy) ^ 2))
    self:move((px - wx) / len * self.speed * dt, (py - wy) / len * self.speed * dt)
    if d > 220 then self.state = "return" end

  elseif self.state == "return" then
    local dx, dy = self.homeX - self.x, self.homeY - self.y
    local len = math.sqrt(dx ^ 2 + dy ^ 2)
    if len < 4 then
      self.state = "wander"
    else
      self:move(dx / len * self.speed * dt, dy / len * self.speed * dt)
    end
  end
end

Mood by mood. Wander: every 1 to 3 seconds pick a random angle and turn it into an x part and a y part with math.cos and math.sin (that is what they're for). Hero within 120 pixels: chase. Chase: point at the hero. Dividing by len makes the direction length 1, so the wisp moves at speed, not faster when you're far away. Hero 220 away: give up. Return: head home, then wander again. The two distances are different on purpose: with one number, a wisp would give up the instant you stepped past the line and walk all the way home before it noticed you again. The gap keeps a chase alive. Draw wisps as circles, a color per mood, so you can see them think:

function Wisp:draw()
  if self.state == "chase" then love.graphics.setColor(0.9, 0.4, 0.5)
  elseif self.state == "return" then love.graphics.setColor(0.5, 0.6, 0.9)
  else love.graphics.setColor(0.6, 0.9, 0.8) end
  love.graphics.circle("fill", self.x + self.w / 2, self.y + self.h / 2, self.w / 2)
end

Now wire them in. In love.load, after the player: wisps = { Wisp(12 TILE, 4 TILE), Wisp(6 TILE, 10 TILE) }. In love.update, after player:move: for i, w in ipairs(wisps) do w:update(dt) end. In love.draw, inside the camera's push/pop, after drawMap(): for i, w in ipairs(wisps) do w:draw() end. Run it. Walk near one. It notices you.

Step 2Hearts

A wisp that notices you should cost you something, or it's a pet. In love.load, add:

  state = "playing"
  hearts = 3
  hurtTimer = 0

At the top of love.update, if state ~= "playing" then return end. Then, after the wisps move:

  hurtTimer = math.max(0, hurtTimer - dt)
  for i, w in ipairs(wisps) do
    if hurtTimer == 0 and overlaps(player, w) then
      hearts = hearts - 1
      hurtTimer = 1.5
      local px, py = player:center()
      local wx, wy = w:center()
      local len = math.max(1, distance(player, w))
      player:move((px - wx) / len * 40, (py - wy) / len * 40)
      if hearts <= 0 then state = "done" end
    end
  end

A touch costs a heart, shoves the hero 40 pixels away from the wisp, and starts a 1.5-second grace period so one brush isn't three hits. Draw the hearts after pop, so they stick to the screen:

  love.graphics.setColor(0.9, 0.3, 0.35)
  for i = 1, hearts do
    love.graphics.rectangle("fill", 10 + (i - 1) * 22, 10, 16, 16)
  end
  if state == "done" then
    love.graphics.setColor(1, 1, 1)
    love.graphics.print("The lantern went out. Space to try again.", 240, 280)
  end

In love.keypressed: if key == "space" and state == "done" then love.load() end. Calling love.load again rebuilds everything from scratch, which is the cheapest restart there is. Now the wisps matter.

Step 3The dialog box

Text that appears all at once is a sign. Text that types itself out is a voice. The dialog is one table of state:

dialog = { lines = {}, index = 1, shown = 0, timer = 0, active = false }

function say(lines)
  dialog.lines = lines
  dialog.index = 1
  dialog.shown = 0
  dialog.timer = 0
  dialog.active = true
end

function updateDialog(dt)
  if not dialog.active then return end
  dialog.timer = dialog.timer + dt
  if dialog.timer > 0.03 then
    dialog.timer = 0
    dialog.shown = math.min(dialog.shown + 1, #dialog.lines[dialog.index])
  end
end

shown is how many characters of the current line are visible; every 0.03 seconds it grows by one. # on a string is its length. Draw string.sub(line, 1, dialog.shown), the first shown characters, with love.graphics.printf so long lines wrap. One warning: # and string.sub count bytes, not letters, so write your lines with plain straight quotes (' and "), no curly quotes or emoji, or a cut-in-half character crashes the draw. Then the space bar:

function advanceDialog()
  local line = dialog.lines[dialog.index]
  if dialog.shown < #line then
    dialog.shown = #line
  elseif dialog.index < #dialog.lines then
    dialog.index = dialog.index + 1
    dialog.shown = 0
  else
    dialog.active = false
  end
end

Three cases, in order: still typing, finish the line; more lines, next one; nothing left, close. Call it from love.keypressed on space while the dialog is active. At the top of love.update, after updateDialog(dt), add if dialog.active then return end: the world holds still while someone is talking. Open the game with say({ "The keep is dark. The wisps don't like the lantern.", "Find the iron key. The far door is locked." }).

Step 4The bag

An inventory is a list of names. That's all it is. Put bag = {} inside love.load, not at the top of the file, so a restart empties it; a bag that survives love.load hands you the key twice.

function hasItem(name)
  for i, item in ipairs(bag) do
    if item == name then return true end
  end
  return false
end

Draw it after love.graphics.pop() so it sticks to the screen: "Bag:", then one line per item, 30 + i * 18 pixels down. It fills up in the next step.

Step 5Keys and locked doors

Room 2 gets a new tile number, 3: a locked door. Use the kit's maps/room2.csv, which has one in the bottom wall, or add a 3 to the room 2 you drew in Build 08. Make it solid unless the bag has the key:

function solidAt(px, py)
  local t = tileAt(px, py)
  if t == 1 then return true end
  if t == 3 and not hasItem("iron key") then return true end
  return false
end

The key itself is just an Entity lying on the floor of room 1 (keyItem = Entity(16 TILE + 8, 11 TILE + 8, 16, 16)), drawn gold. In love.update:

  if keyItem and overlaps(player, keyItem) then
    table.insert(bag, "iron key")
    keyItem = nil
    say({ "You found the iron key." })
  end

keyItem = nil deletes it; the if keyItem and ... guard skips the check once it's gone. Walk over it and the locked door in room 2 stops being a wall. No door code needed; solidAt already asks the bag. Jamie wanted the key to be "more of a vibe." It is a table with four numbers.

Step 6Putting it together

Order matters. love.update: dialog first (return if active), hero's move, every wisp's update, wisp touches, pickups, camera. love.draw: map, items, wisps, hero inside the camera; hearts, bag and dialog outside it. If something draws in the wrong place, check this first.

Step 1States: the game is in exactly one mood

Right now the game starts playing the instant it opens, and crashing just wipes the score. Finished games have states: title, playing, game over. The game is in exactly one state at a time, and update and draw behave differently in each. This is called a state machine, and it's the single most useful idea in this whole course.

Add to love.load:

  state = "title"

Then split love.update with an if:

function love.update(dt)
  if state == "playing" then
    -- everything you wrote in Build 02 goes here, indented one level
  end
end

And in love.draw:

function love.draw()
  if state == "title" then
    love.graphics.print("METEOR DRIFT", 300, 220)
    love.graphics.print("press space to launch", 300, 260)
  elseif state == "playing" then
    -- all your Build 02 drawing
  elseif state == "gameover" then
    love.graphics.print("SHIP LOST", 320, 220)
    love.graphics.print("score: " .. score, 320, 250)
    love.graphics.print("press space to retry", 300, 290)
  end
end

elseif chains questions: the first true branch runs, the rest are skipped. Now the only thing that changes state is a key press:

function love.keypressed(key)
  if key == "space" then
    if state == "title" or state == "gameover" then
      resetGame()
      state = "playing"
    end
  end
end

Write resetGame() yourself: it sets score, fuel, rocks, fuels, the timers, and the ship's position back to the way love.load had them. Then make love.load call resetGame() too, so the start values live in one place. Finally, where a crash used to wipe the score, set state = "gameover" instead. Run it: title, play, crash, retry.

Step 2A font you can read

The default font is tiny. Nobody knows why. Make two in love.load and switch between them:

  bigFont = love.graphics.newFont(40)
  smallFont = love.graphics.newFont(18)

love.graphics.setFont(bigFont) before the title text, setFont(smallFont) before everything else. Fonts are made once in load and used in draw; making one every frame would slow the game down. That rule covers images and sounds too.

Step 3Real art (Kenney, CC0)

Kenney makes free game art under the CC0 license, which means anyone may use it for anything, no credit required (we credit anyway, because that's what decent studios do). Open the Space Shooter Redux pack from the link in this module, download it, and unzip it. Inside you'll find dozens of PNG ships and meteors. Pick one ship and one meteor you like. Make a folder named assets inside your build folder and copy them in. Rename the ship image to ship and the meteor image to rock, keeping the png ending on both.

Load them once:

  shipImage = love.graphics.newImage("assets/ship.png")
  rockImage = love.graphics.newImage("assets/rock.png")

Draw the ship with the image instead of the triangle:

  love.graphics.setColor(1, 1, 1)
  love.graphics.draw(shipImage, ship.x, ship.y, 0, ship.w / shipImage:getWidth(), ship.h / shipImage:getHeight())

Those last two numbers are scale: the image's real size divided into the size we want, so a 99-pixel-wide PNG becomes our 40-pixel ship. setColor(1, 1, 1) first, or the image gets tinted by whatever color was set last. Do the same for rocks inside the rock loop. Keep the collision rectangles exactly as they were; the picture is just paint on top of the math.

Want it to look like yours? Open your PNG in any paint program and recolor it. That's allowed, and it's how real small studios work. (Jamie would like you to know that recoloring is "basically art.")

Step 4Sounds you made yourself

Open the sound tool linked in this module (a free in-browser synth, no account). Press the Pickup/Coin button until you hear one you like, then export it as a WAV named fuel.wav. Press Explosion for a crash sound, crash.wav. Put both in assets. Load once:

  fuelSound = love.audio.newSource("assets/fuel.wav", "static")
  crashSound = love.audio.newSource("assets/crash.wav", "static")

Then fuelSound:play() where fuel is grabbed and crashSound:play() where the ship is lost. The colon in fuelSound:play() means "call play on this sound"; you'll see colons whenever a table has its own functions.

Step 5The ramp

A game that never gets harder gets boring in a minute. Add spawnLimit = 0.8 to resetGame, use it instead of the number 0.8 in the timer check, and every time a rock spawns do:

    spawnLimit = math.max(0.25, spawnLimit - 0.01)

math.max keeps it from dropping below a quarter second. Play a round and feel the pressure build. If you last past 30 seconds, you've beaten the lead dev. I'm not proud of that.

Step 1Sprite sheets and quads

Game art comes on a sprite sheet: one PNG holding many small frames in a grid. Open the Kenney Pixel Platformer pack from the link in this module, find the characters sheet, and copy it into assets/sheet.png. Each character frame in that pack is 24 by 24 pixels and the frames sit side by side. (Don't want Kenney's hero? Draw your own 48-by-24 PNG in any paint program with two 24-by-24 frames in it. Jamie did this in four minutes and it was, to be fair, pretty good.)

A quad is a rectangle that says "this part of the image." Make one per frame, once:

  sheet = love.graphics.newImage("assets/sheet.png")
  sheet:setFilter("nearest", "nearest")
  frameSize = 24
  frames = {}
  for i = 0, 1 do
    table.insert(frames, love.graphics.newQuad(i * frameSize, 0, frameSize, frameSize, sheet:getDimensions()))
  end

setFilter("nearest", "nearest") tells LÖVE to scale pixels as crisp squares instead of blurring them, which is the difference between pixel art and a smudge. Now draw the hero with a frame instead of a rectangle:

  love.graphics.setColor(1, 1, 1)
  love.graphics.draw(sheet, frames[1], player.x, player.y, 0, player.w / frameSize, player.h / frameSize)

Run it. Your square is a person. Keep the collision math exactly as it was; the picture is paint on top of the box.

Step 2Animation

Animation is a flipbook inside the flipbook: swap which quad you draw every so often. A tiny table keeps track:

  anim = { frame = 1, timer = 0, rate = 0.12 }

In love.update, only while a direction key is held:

  local moving = love.keyboard.isDown("left") or love.keyboard.isDown("right")
  if moving then
    anim.timer = anim.timer + dt
    if anim.timer > anim.rate then
      anim.timer = 0
      anim.frame = anim.frame % #frames + 1
    end
  else
    anim.frame = 1
  end

anim.frame % #frames + 1 is the wrap trick: with two frames it goes 1, 2, 1, 2. Change the draw call to frames[anim.frame]. Run it and hold right. It runs. Change rate and feel how speed of frames is a feeling, not a number.

Step 3Particles

Particles are the same loop pattern as rocks: a list of tiny things that spawn, move, and die. On every jump, burst eight of them from the hero's feet. Add particles = {} to resetGame, then in the jump code:

    for i = 1, 8 do
      table.insert(particles, {
        x = player.x + player.w / 2, y = player.y + player.h,
        vx = math.random(-120, 120), vy = math.random(-60, 40), life = 0.5
      })
    end

Move and age them in love.update, backward loop as always:

  for i = #particles, 1, -1 do
    local pt = particles[i]
    pt.x = pt.x + pt.vx * dt
    pt.y = pt.y + pt.vy * dt
    pt.life = pt.life - dt
    if pt.life <= 0 then table.remove(particles, i) end
  end

Draw them inside the camera's push/pop, fading as they die:

  for i, pt in ipairs(particles) do
    love.graphics.setColor(1, 1, 1, pt.life * 2)
    love.graphics.rectangle("fill", pt.x, pt.y, 4, 4)
  end

The fourth number in setColor is alpha: 1 is solid, 0 is invisible. life * 2 starts at 1 and slides to 0. Jump. Dust. This is the first thing a playtester notices and the last thing a programmer thinks to add.

Step 4Screen shake

Screen shake is a lie told to the camera: for a fraction of a second, draw everything slightly off. Add shake = 0 to resetGame. When the hero falls out:

  if player.y > cameraY + 650 then
    shake = 0.5
    state = "gameover"
  end

In love.draw, at the very top, before anything else:

  if shake > 0 then
    love.graphics.translate(math.random(-6, 6), math.random(-6, 6))
    shake = shake - love.timer.getDelta()
  end

love.timer.getDelta() is dt for places that don't get handed it. Since the game-over screen is drawn every frame, the shake plays out there, then stops. Play, fall, feel it. Then halve the 6 and see whether you like it better. (You will. Everyone overdoes shake the first time.)

Step 5Saving to disk

LÖVE gives every game a private save folder, and two functions: love.filesystem.write(name, text) and love.filesystem.read(name). Let's count how many runs this hero has had. In love.load:

  runs = 0
  if love.filesystem.getInfo("runs.txt") then
    runs = tonumber(love.filesystem.read("runs.txt"))
  end

getInfo answers "does this file exist?" so the first launch doesn't crash; tonumber turns the saved text back into a number. Every time a game starts, in resetGame:

  runs = runs + 1
  love.filesystem.write("runs.txt", tostring(runs))

Print runs on the title screen. Quit the game. Open it again. The number remembers. That's persistence, and every save system you've ever used is this with more steps.

The Set List

How it works. A set is not just jokes in a pile. It has a shape: a short, confident opener that sets up one thing, bits that build with bigger stakes each time, and a closer that calls back to the opener.

Three comedians dropped their set lists. Each has five bits, all shuffled. Tap the bits in order to fill slots 1 to 5. The last screen counts how many sets you put in order with no wrong taps.

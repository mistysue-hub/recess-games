# GAME: STRATEGY TOURNAMENT
Five robots play Cooperate or Cheat (same payoffs as Last Round) against each other and a copy of themselves.
SAINT always cooperates. SHARK always cheats. COPYCAT copies your last move. GRUDGE cooperates until you cheat once, then never again. ONE-STRIKE punishes a mismatch for one round.
After each round, a match keeps going with a set chance: 20%, then 60%, then 90%.
Before each tournament, back the robot you think will win.
Game: https://mistysue-hub.github.io/recess-games/game-theory/t4-m03-strategy-tournament.html

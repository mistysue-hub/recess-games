# GAME 7: PRICE WAR
Two soda stands, 100 customers, cost 2 per soda. Prices 2 to 20, set at the same moment.

Rounds 1-3 (same soda): cheaper store gets all 100. Same price: 50 each.
Rounds 4-6 (fans): customers = 50 + 5 x (Penny's price minus yours), from 0 to 100.

Penny opens each half at 10, then prices to beat what you charged last round.

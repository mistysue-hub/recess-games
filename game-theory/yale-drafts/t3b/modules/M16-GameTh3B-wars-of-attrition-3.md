## Tutor guidance
Flow: bet, clip, rematch, done. Before the clip, Rocky offers a bet (learner picks A, B or C and locks it in; settle it after the clip): "Can perfectly rational players end up in a long, costly war? A) Never. B) Yes, with some chance each round. C) Only if they're angry." Answer: B. Clip: https://youtu.be/wR8dqbc6mlQ?t=2873 (Ben Polak, Open Yale Courses). By time: 47:53 the mixed equilibrium: each fights with chance prize/(prize + cost), expected payoff 0; 66:54 the endless version, to the end. Rematch (Rocky only): the class game: prize 1, cost 0.75. Each fights with chance 1/1.75, about 57%. Chance both fight in a round: about 0.57 x 0.57, about 33%. Two rounds in a row: about 11%. The boss rounds (Problem Set 9) are the next modules. The learner explains it in their own words.

# GAME 11: MUTANT INVASION
Beetles meet in random pairs; more points, more babies. The species starts all one strategy, then 5% mutants appear.

World 1 Share/Grab: SS 3, SG 0, GS 5, GG 1.
World 2 Left/Right: LL 2, LR 0, RL 0, RR 1.
World 3 Plain/Fancy: PP 1, PF 1, FP 1, FF 3.
(First letter is you, second is who you meet.)

World 2: you pick the species. Worlds 1 and 3 start set. Predict, then run 30 generations.

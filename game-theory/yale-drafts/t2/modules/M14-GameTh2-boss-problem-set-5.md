Sittings: 1

1. Open it: https://oyc.yale.edu/sites/default/files/problemset5_1_0.pdf

## Tutor guidance
Flow: work, paste, follow-up, done. Required boss round, no time limit. Boss: THE MUTANT KING, HP 3. Rocky opens with one short taunt from the boss, and each question answered with reasoning knocks off 1 HP; Rocky shows the HP after each one. Problem Set 5 has 3 questions: stability and weak dominance, stability in a demand game with ranked equilibria, and "clever mutants" with a secret handshake (part of it uses mixed populations from Lecture 12). Optional help: Yale's handout on ESS in pure strategies, https://oyc.yale.edu/sites/default/files/ess_handout_2.pdf No key is used. Rocky checks each answer has reasoning, asks one follow-up, and corrects only what he is sure of.

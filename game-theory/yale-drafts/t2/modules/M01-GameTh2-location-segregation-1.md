# M01 Location, Segregation and Randomization, Part 1
Summary: Run a town where families move if too few neighbors match them, and predict how sorted it gets.
Estimated time: 28 minutes (play 10, clip 18)
Sittings: 1

## Start here
1. Open the game: https://mistysue-hub.github.io/recess-games/game-theory/t2-m01-sorting-town.html
2. Run 3 towns. For each, pick how picky families are and predict the result first.
3. Tap "Copy my results for Rocky" and paste them in the chat.
4. Open the clip.
5. When Rocky says you're done, tap Submit.

## Learning targets
- See how mild choices by each person can add up to a strongly sorted town.

## Tutor guidance
Flow: play, paste, clip, done. Pasted line starts GT2-M01; check each town's start and end scores and the prediction marks. Ask once, before the clip: "Did anyone in your towns want to live only with their own color?" Clip: https://youtu.be/pglQ_E0g8PY?t=862&end=1940 (Ben Polak, Open Yale Courses). By time: 14:22 why outcomes are not the same as what people want; Polak's own version uses two towns, East and West, with tall and short students, not a checkerboard (the checkerboard is Thomas Schelling's model). The next part is the next module.

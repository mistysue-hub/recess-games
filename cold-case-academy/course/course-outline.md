# Cold Case Academy: Unsolved Crimes in History — Course Outline (DRAFT)

**Audience:** ages 10–13 (grades 5–8)
**Kind:** BLUEPRINT goal template
**Module segment:** `Case` → files named `M<NN>-Case-<slug>.md`, readings named `resources/M<NN>Case.md`
**Reading look:** a manila case-file folder — cream/manila background, typewriter-style monospace headings, a red "CASE FILE" stamp, evidence items as pinned index cards. (Unique to this course.)
**Session flow (every module):** hook vote → case-file reading → finished-too-fast check (75% rule) → look back at vote → talk-back (2 questions) → activity (one or two) → complete
**Content rule for the whole course:** heists, escapes and disappearances only. No gore, no graphic violence. Every reading is an original case file written for the course (not copied from any book).

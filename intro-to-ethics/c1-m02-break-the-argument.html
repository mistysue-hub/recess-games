    Sixty-second recap

    Ethics asks two big questions: what makes a life go well for the person living it (well-being), and what we owe each other (morality). Philosophers answer them with arguments.

    An argument is a package: some claims, called premises, offered as support for one more claim, the conclusion. Signpost words help: "so" and "therefore" usually mark a conclusion; "because" and "since" usually mark a premise.

    Exhibit B: an argument, laid out flat 1. Anyone on the team has to come to practice. 2. Jordan is on the team. So, Jordan has to come to practice.

    This file is about the next question: when does an argument actually work?

    Valid is not the same as true

    Here is the single most useful idea on this page. An argument is valid when the conclusion has to be true if the premises are true. There's no way to have the premises true and the conclusion false at the same time.

    Validity is about the connection, not about whether the premises are actually true. Which leads to some gloriously silly results:

    Exhibit C: valid, and completely ridiculous 1. Every planet is made of cheese. 2. Mars is a planet. So, Mars is made of cheese.

    Premise 1 is false. But if it were true, and premise 2 is true, Mars would have to be cheese. The connection is airtight, so the argument is valid. It just doesn't prove anything, because it starts from garbage.

    That's why we need a second word. An argument is sound when it's valid and all its premises are actually true. A sound argument is the real deal: its conclusion must be true.

    Flip side, which trips up almost everyone: an invalid argument can have every line true. "Paris is in France. Water is wet. So the Pacific is the largest ocean." True, true, true. But France and water could be exactly as they are while some other ocean was the biggest, so the premises don't guarantee the conclusion. Invalid.

    How to break an argument

    So how do you prove an argument is invalid? You don't need to show the conclusion is false in real life. You only need to describe one possible situation where every premise is true and the conclusion is false. That situation is called a counterexample. It can be as weird as you like, as long as it's possible.

    Logicians also have a cheat code. For most arguments you'll meet, validity depends on the argument's shape, not its topic. So keep the shape, swap in new words, and see if you get true premises with a false conclusion:

    Exhibit D: same skeleton, new skin Original: All poets are dreamers. Kai is a dreamer. So Kai is a poet. Same shape: All cats are mammals. My dog is a mammal. So my dog is a cat.

    The second one has true premises and an obviously false conclusion. Same shape, so the first one is invalid too, even if Kai happens to be a poet.

    The fine print: a few arguments are valid because of what particular words mean rather than their shape. "Ana is taller than Ben, and Ben is taller than Cy, so Ana is taller than Cy" works only because of how "taller than" behaves. Swap in "is the mother of" and the same shape breaks. When in doubt, go back to the definition: can you describe a situation with true premises and a false conclusion?

    One more tool for the machine below. "Every dragon is a reptile" and "No dragon flies" both count as true in a world with no dragons at all: there's no dragon around to break them. Logicians call this vacuously true. (But "Some dragon..." is false with no dragons, because "some" means at least one exists.)

    The rule that makes arguing worth it

    Here's why any of this is worth your time.

    Suppose someone hands you a valid argument, and you hate the conclusion. You are not allowed to just say "nah." Because the argument is valid, the only way its conclusion can be false is if at least one premise is false. So you owe them an answer to one question: which premise?

    That's the move that turns a fight into progress. Instead of "you're wrong" versus "no, you're wrong," you get "I accept premise 1, I accept premise 2, but I think premise 3 fails, and here's a case that shows it." Now you're actually disagreeing about something specific, and one of you might learn something.

    There's an old philosophers' saying: one person's proof is another person's refutation. If I accept the premises, I'm stuck with the conclusion. If you reject the conclusion, the same valid argument shows you that a premise is false. Logic tells you something has to give. It doesn't tell you what.

    Missing pieces, and one cheat

    Logicians and newscasters mean different things by "begging the question."

    Real arguments skip steps. "Lying hurts people, so lying is wrong" leaves something out. As written, it's invalid: the premise alone doesn't rule out a situation where lying hurts people and still isn't wrong.

    To make it valid, add the missing premise that bridges the gap: "Anything that hurts people is wrong." Now the conclusion follows. And look what happened: the premise you had to add is exactly where a critic would aim. Dentists hurt people. Is a filling wrong? Digging out the hidden premise shows you where the real disagreement lives.

    One cheat to watch for. You can make any argument valid by adding the conclusion itself as a premise. "Lying is wrong. So lying is wrong." Technically valid, since the premise can't be true while the conclusion is false. But it proves nothing, because it assumes exactly what it was supposed to show. Philosophers call this begging the question. (That's the original meaning of the phrase. It doesn't mean "raises the question.")

    The gap that's hard to jump

    Spot the pattern. "Most people tip at restaurants. So you ought to tip." The premise is about how things are. The conclusion is about how things ought to be. Even if the premise is true, the argument is invalid as it stands: everyone could tip and you still might not be obliged to. To close it, you'd need a premise with an ought in it, like "you ought to do what most people do" (and good luck defending that one).

    The Scottish philosopher David Hume pointed at this in A Treatise of Human Nature (1739 to 1740). He complained that writers would describe how things are and then, without warning, start talking about what ought to be. Philosophers now call this the is/ought gap. Many think no pile of facts about what is can validly get you to a real ought unless some premise already has an ought in it.

    Logicians, starting with Arthur Prior around 1960, have found tricky technical exceptions, but none that settles a real moral question. Whether the gap is real at all is still argued about.

    Practical upshot: in any valid argument for a moral conclusion, hunt for the premise with the "ought" or "wrong" in it. That's usually the one doing the real work, and the one worth arguing about.

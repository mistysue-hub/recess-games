Reusable Spells

Write it once. Name it. Cast it whenever you want.

You've been using methods since Mission 01: WriteLine is one. A method is a named chunk of code you can run by calling its name. Now you'll write your own.

Program.csC#
1void Shout(string words)
2{
3    Console.WriteLine(words.ToUpper() + "!!!");
4}
5
6Shout("hello");
7Shout("we have cookies");
voidthis method gives nothing back; it just does something.Shoutthe name you chose. Call it with Shout(...).string wordsa parameter: a box the caller fills in each time.

Some methods hand a result back. Swap void for the type of the answer, and use return:

Program.csC#
1int Area(int width, int height)
2{
3    return width * height;
4}
5
6int bedroom = Area(4, 3);
7Console.WriteLine($"Bedroom: {bedroom} square meters");
8Console.WriteLine($"Garage: {Area(6, 5)} square meters");
⚠ HEADS UP
A method must be called with exactly the boxes it asks for. Area(4) with one number, or Area(4, 3, 2) with three, makes SHARP refuse to move. Count the parameters.

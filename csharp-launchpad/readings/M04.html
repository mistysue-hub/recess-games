Fork in the Road

Teach SHARP to make a decision. Carefully. It will take you literally.

So far SHARP has done every line, every time. Now you'll make it choose. The tool is if: a question that is either true or false, then a block of code that only runs when the answer is true.

Program.csC#
1int temp = 38;
2if (temp > 30)
3{
4    Console.WriteLine("Wear shorts.");
5}
if (...)the question goes in parentheses.{ }the curly braces hold the code that runs only when the answer is true.>greater than. Also: < <= >= == (equal) != (not equal).
⚠ HEADS UP
One = puts a value in a box. Two == asks "are these equal?" Mixing them up is the number one beginner bug on Earth. In some languages it quietly breaks your program; SHARP is stricter and refuses to run it at all.

Add else if for more questions and else for "none of the above." SHARP checks them top to bottom and runs the first one that's true, then skips the rest.

Program.csC#
1if (temp > 30)
2{
3    Console.WriteLine("Wear shorts.");
4}
5else if (temp > 15)
6{
7    Console.WriteLine("Jacket weather.");
8}
9else
10{
11    Console.WriteLine("Coat. Hat. Everything.");
12}

When you're comparing one box against a list of exact values, switch is tidier than a pile of ifs:

Program.csC#
1string door = "red";
2switch (door)
3{
4    case "red": Console.WriteLine("Dragon."); break;
5    case "blue": Console.WriteLine("Treasure."); break;
6    default: Console.WriteLine("A wall."); break;
7}

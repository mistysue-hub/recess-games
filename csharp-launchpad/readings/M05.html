Do It Again

Never type the same line twice. That's what SHARP is for.

A loop runs a block of code again and again. There are three flavors. First, the for loop, when you know how many times:

Program.csC#
1for (int i = 1; i <= 5; i++)
2{
3    Console.WriteLine($"Lap {i}");
4}
int i = 1start: make a counter box.i <= 5keep going while this is true.i++after each lap, add 1 to i.

Second, the while loop, when you don't know how many times, only when to stop:

Program.csC#
1int fuel = 10;
2while (fuel > 0)
3{
4    Console.WriteLine($"Fuel: {fuel}");
5    fuel = fuel - 3;
6}
7Console.WriteLine("Empty.");
⚠ HEADS UP
A while loop whose question never becomes false runs forever. SHARP will happily do that. If the editor freezes, that's probably you. Check that something inside the loop changes the box in the question.

Third, foreach, for walking through a collection one item at a time. You'll meet it properly next mission.

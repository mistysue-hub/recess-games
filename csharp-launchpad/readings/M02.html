Boxes with Labels

Give SHARP a memory. Then make it tell a story.

A variable is a box with a label. You put a value in the box, and later you use the label to get it back. SHARP has unlimited boxes, but it is picky about what goes in each one.

Making a box takes three parts: the type of thing it holds, the label, and the value.

Program.csC#
1int age = 12;
intthe type: whole numbers only.agethe label you pick.12the value that goes in the box.

Four types you'll use constantly:

Program.csC#
1int lives = 3;              // whole numbers
2double height = 1.52;       // numbers with a decimal point
3string hero = "Kai";        // text, always in double quotes
4bool hasKey = true;         // true or false, no quotes

To print a box inside a sentence, put a dollar sign before the opening quote and wrap the label in curly braces. SHARP swaps the label for the value.

Program.csC#
1Console.WriteLine($"{hero} has {lives} lives.");
⚠ HEADS UP
Forget the $ and SHARP prints the curly braces and the label as plain text. Do it once on purpose. You'll do it by accident later anyway.

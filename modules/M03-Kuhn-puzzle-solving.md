# Puzzle-Solving

Summary: Normal science solves puzzles the paradigm promises can be solved; Halley's comet's return tested the calculation, not Newton's laws, which nobody questioned. Popper thought scientists should try to prove ideas wrong.

**Start here:** use the level chosen in M01 → say the hook word for word → open the reading at that level → AGENTS.md session flow.

Estimated time: 25 minutes (reading about 6, talk about 9, game about 10).

## Learning targets

- describe normal science as puzzle-solving, using Halley's comet
- contrast Kuhn's normal science with Popper's falsification

> Quick vote before you read. True or false: a scientist whose result contradicts their field's big theory will usually check their own work first. How sure are you, 0 to 100?
